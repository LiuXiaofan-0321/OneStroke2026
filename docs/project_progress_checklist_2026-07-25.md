# OneStroke2026 项目进度清单（模型 + 开发）

更新日期：2026-07-25  
当前阶段：SegFormer-B2 v1 单种子消融完成；前端开发完成；后端模型服务与真实联调尚未完成。

## 1. 当前结论

- 模型侧已经完成可信数据闭环、U-Net 重测、SegFormer-B2 的 B0/B1/B2 三组正式实验。
- B2 是当前五方向分割和边界质量最好的模型，可作为现阶段候选教师模型。
- B2 的五方向 Macro Dice 为 `0.9610`，相比 U-Net 的 `0.8914` 提升约 `6.97` 个百分点。
- B2 的 Boundary F1 为 `0.8348`，相比 U-Net 的 `0.7385` 提升约 `9.62` 个百分点。
- 关键点仍是主要短板：B2 Keypoint F1 为 `0.7159`，低于 U-Net 的 `0.7530`。
- 当前不能宣布模型模块全部定型：关键点专项改进、困难集评测、三随机种子和推理交付仍未完成。
- 开发侧已完成前端开发；下一阶段重点是业务后端、模型服务、真实接口联调和部署验收。
- 字体选择已经进入产品方案，但当前 SegFormer v1 是字体无关分割模型，尚不依据 `target_style_id` 改变分割或评分。

### 2.2 已完成：B0/B1/B2 单种子消融

三组实验保持相同数据、划分、SegFormer-B2、随机种子、增强、优化器和学习率策略，只逐项改变损失设计。

| 实验 | 方向损失 | 关键点损失 | 边界损失 | Macro Dice | Macro IoU | Keypoint F1 | Boundary F1 |
| --- | --- | --- | --- | ---: | ---: | ---: | ---: |
| U-Net | 旧方案 | 旧方案 | 无 | 0.891350 | 0.804875 | 0.753010 | 0.738529 |
| B0 | 加权 BCE + Dice | BCE + Dice | 无 | 0.955282 | 0.914415 | 0.713028 | 0.808364 |
| B1 | 加权 BCE + Dice | Focal + Dice | 无 | 0.955414 | 0.914657 | 0.713854 | 0.807672 |
| **B2** | 加权 BCE + Dice | Focal + Dice | `0.2` | **0.961049** | **0.925051** | **0.715935** | **0.834753** |

结论：

- [x] B0 证明 SegFormer-B2 主体对方向分割有效。
- [x] B1 证明当前 Focal 配置对关键点提升很小，不能宣称 Focal Loss 显著有效。
- [x] B2 证明 Boundary Loss 对方向掩码和边界质量有明确增益。
- [x] 当前模型候选确定为 B2，但仅代表“方向分割/边界”当前最优。
- [x] B2 验证集校准后阈值已固化在 `thresholds_val.json`；测试集未参与阈值搜索。
- [x] B2 测试阈值：vec1 `0.9109`、vec2 `0.8713`、vec3 `0.9109`、vec4 `0.9307`、vec5 `0.9307`、keypoint `0.2582`。

## 5. 推荐执行顺序

1. 立即备份 B2 checkpoint、阈值、指标和日志，随后关闭租用 GPU，停止无效计费。
2. 模型组本地完成关键点标签统计、失败可视化和专项实验设计。
3. 开发组并行实现业务后端和异步任务接口，继续使用 Mock 模型结果。
4. 用一次短 GPU 实验验证关键点改进；若有效，再确定最终模型。
5. 最终模型运行3个随机种子，并完成困难集与人工复核。
6. 封装推理服务，与已完成前端进行真实联调。
7. 完成部署、端到端测试、项目报告和论文实验表。
