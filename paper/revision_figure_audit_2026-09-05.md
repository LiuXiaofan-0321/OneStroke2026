# OneStroke2026 图稿视觉审阅与修改建议

审阅日期：2026-09-05。审阅对象：本轮修改开始时 `paper/figures/redrawn/` 中的全部七张 PNG，并对照正文图注。本文记录原图优点与可执行建议，不代表对本轮重绘成品的验收。所有建议均以保留原始图像、掩膜、冻结样例和统计结果为前提，不要求重跑模型。

总体判断：现有图已具备真实样例、统一通道配色、明确样本来源和失败案例，科学表达基础比纯装饰性示意图扎实。主要问题是信息层级、面板密度、统计结论用语和正文与图的衔接；单纯换颜色不会解决。目标应是缩印后可读、证据可核查、结论不误导。没有客观的“超越 CCF-A / Nature”图形等级，不能据此承诺发表层级。

## 图 1：整体流程

**值得保留：** 从输入、方向掩膜、配准差异到可检查输出使用同一真实样例；缺失与多余墨迹有纹理冗余编码；低分的跨风格样例如实呈现了结构差异。

1. 顶部图像与底部流程名称之间建立更直接的对应，统一面板顶线和底线；保留一次流程箭头即可，减少底部长条的视觉重量。
2. 面板 b 的右下 inset 实际是缩小展示，不是放大，且遮住完整掩膜。优先移到图外成为真正的局部放大，或删除重复小图；不能让读者误以为它展示了更高分辨率证据。
3. 面板 e 将 `Weakest direction / Direction Dice` 合为“Lowest direction Dice: vec4, 0.00”，避免把该方向数值误读成五通道平均值。`Masks: six` 等重复规格可移到图注。
4. 面板 d 展示 3×3 网格，却在下面同时列出 polar / grid / projection 三个数值。增加清楚的“spatial similarities”标识，或在概览图中仅保留与实际图形对应的示意，将具体数值留给图 6。
5. 将“跨风格示例”放到输入附近的小字中，帮助读者正确理解 12.9 分。无需更换低分样例来使系统看起来更好。

## 图 2：六通道标注定义（重点）

**值得保留：** 独立笔画、完整字、重叠标签、端点来源和全部六通道均来自同一样本；黑色表达多标签重叠，正确体现方法的核心。

1. 原图有 a–l 共 12 个近似同等级面板，上排宽窄不齐，方向图例和终点定义重复出现。改为三个读图层级：原始采集与标注来源 → 多标签重叠的关键证据 → 六通道输出。不要让每一项辅助说明都成为独立大面板。
2. “一处像素可属于两个方向”应成为视觉中心。选择现有冻结交叉位置，使用有定位框的局部放大，并直接标注该处的两个通道。局部区域不需要大到挤压完整字符和端点来源。
3. 方向图例缩成统一横排，保留方向小图标和 `vec1–vec5` 的对应关系。五种颜色、文字和符号共同编码，不能只靠红绿区分。
4. 下排六通道使用同样大小的图框、相同坐标范围、统一标题基线。完整字符上的端点轮廓与纯端点通道应各承担一种解释任务，避免重复堆叠。
5. 交叉处的青色端点标记不要遮住黑色多标签像素。原始端点通道保持不变；如为了展示放大标记，图注必须明确这是显示处理。
6. 保留原始黑白字、原始通道掩膜及其像素边界。只修改排版和矢量注释，不用生成式图像补画笔画、不平滑成更漂亮的掩膜。

## 图 3：数据资源与质量控制

**值得保留：** 40 个字类的一致网格提供真实的数据覆盖感；全部七对跨风格样例避免挑选“最好看”的几对；正文区分人工 GT 与模型缓存掩膜。

1. 上半部 a–d 再次重复图 2 的标注过程，占用了本图解释数据规模和划分的空间。压缩成简洁采集卡片，或者改为“人工标注项目语料 / 外部参考库”两条清楚的来源路径。
2. QC 图应明确显示完整链条：894 recovered → 排除 54 个缺少方向映射的样本 → 840 complete → 排除 12 mismatches 与 59 duplicates → 769 QC-clean。原图虽有 894 和 840，但没有显式解释两者之间的 −54。
3. 当前 −12、−59 是很窄的空心条，视觉上容易被读作普通数据条。采用清晰的减项标注或有共同基线的审计流程，保留精确计数。
4. 在 QC 总数附近补充两种划分的简洁记录：standard 530/119/120，character-disjoint 539/114/116；是否占图内空间由版面决定，避免把本已完整的数据表再复制一遍。
5. 40 类与七对外部样例保持各自一致的尺寸。图内显式标识“人工标注语料”与“模型缓存的参考掩膜”，防止视觉上混淆标签性质。许可和完整来源留在图注，图内只保留必要短注。

## 图 4：分割定性对照

**值得保留：** 五列对照整齐，GT 与模型使用同一颜色语义、同一标记位置；同时显示交叉、端点和未见字，未隐藏明显的方向归属错误。

1. 左侧说明列太宽且文字量大。行名保留“Crossing / Endpoints / Unseen identity”，样本 ID 和协议用小一号单行；详细观察移入图注，将空间还给真实掩膜。
2. 圆圈和矩形标记应在 GT 与三个模型中完全对应，现有策略正确。若交叉或端点仍难辨，只为已有标记区域增加等尺寸小放大，避免新增任意挑选区域。
3. 底部三组 Macro Dice 是整个 character-disjoint 测试集的统计值，却紧贴单个样例。另设明显的“Dataset-level, 3 seeds”窄条，避免误读成此样例的分数。
4. “black smears”可改为“excess overlap / direction-label errors”等更具体表述。黑色本身在 GT 中也是合法多标签，图注应说明问题是位置和范围错误，而不是出现黑色就算错误。
5. 不需要为了让某个模型看起来更强而改样例；通过一致的缩放、标注和空白即可提高比较效率。

## 图 5：配准消融

**值得保留：** 三种配准政策面对同一参考、同一扰动；影像证据与数值并列；右侧统一 0–100 轴，避免不同尺度制造改善幅度。

1. 扰动名称全部竖排，阅读费力。移到每行开头或上方成为水平短标题，保留严重度数值与单位。
2. 右侧曲线箭头只是连接两个离散条件，容易显得像有连续变化轨迹。改为配对点/水平连接线，并明确三种形状代表三种政策；不需要拟合线。
3. production 与 wide 的数值在前两行相同，两个点目前主要靠上下错位辨认。让每行内三种政策处于固定小偏移，且图例与图像列标题一致。
4. “Wide similarity”补充为“Wider, coarser grid”，或在图注说明扩大范围时网格点数保持不变。这样图像不会暗示消融只改变搜索范围。
5. 下方两种扰动都出现较高残差，不应把“结构扰动得分下降更多”自动等同于诊断更准确。图注使用“structural penalty increases / remains measurable”，保留正文关于质心重拟合的解释。

## 图 6：ASDS 机制与 direct-ink 对照

**值得保留：** 同一自然样例贯穿机制图与统计散点；实际分量值、权重和总分可相互核验；两种输入与人评分的相关性以及两种分数间关系都被展示。

1. 上排机制密集于左侧，公式与 83.1 分占据很宽的空白区，而下排总标题很长。将机制与验证作为两个明确区域，压缩公式区，保证下排坐标标题和统计注释有足够空间。
2. polar occupancy 目前只有一个 4×8 矩形热图，读者不容易理解极坐标分箱。增加小型“4 环 × 8 扇区”定义示意，再以箭头对应到矩阵；不添加新的特征或计算。
3. 两幅 occupancy 图需要明确数值色标。若两者分布量级不同，应使用分别标注的色标；不能无说明地用不同色系和自动范围暗示可直接比较。图注写明展示的是归一化分布的绝对差，而不是墨迹本身。
4. projection 面板应补上纵轴含义，例如“normalized ink mass”，把颜色的 candidate/reference 含义与实虚线的 row/column 含义分成两组小图例。
5. 下排标题的“same human association”收窄为“closely matched associations in the development cohort”。显示差值与其区间（Δρ≈0.0004，95% CI 约 −0.0101 至 0.0103）比三个四舍五入为 0.556 的数字更能说明证据边界。相关性相近不等于正式等效检验。
6. 两个“人评分—ASDS”图保留相同坐标范围。两分数对照图保留 identity line；如采用透明度改善重叠，只改变显示，不给原始评分加未经说明的随机抖动。

## 图 7：诊断成功与失败

**值得保留：** 同时呈现成功和失败；把真实变化、预测位置、审计结论放在同一行；明确展示“多格真值但只接受单格”的评价限制，比只给自然语言反馈更有说服力。

1. 右侧输出直接展示长的代码字段与竖线，视觉负担大。改为紧凑字段表：finding / direction / missing-or-extra / predicted cell / truth cells；完整机器字段可保留在图注或补充材料。
2. localized evidence 面板内出现较亮的网格与重叠边线。统一网格为低对比灰线，真值用实线、预测用虚线；避免未进入图例的黄色或青绿色辅助线成为新的视觉语义。
3. 成功例的真实局部变化很小，增加该处的固定裁切放大比放大整字有效；原图完整字仍保留用于定位。
4. 底部单条堆叠条无法清楚呈现 1.1% 和 0.3% 两类，文字还挤到右下角。改为五行水平条加 count 与 percentage 列，或三大类主条加两小类旁注，确保五类均可读。
5. 总标题用“Assigned primary categories of 3,565 failures”，明确分类采用固定优先顺序。全图不要把 53.9% 的分类占比呈现成已被实验独立证实的唯一因果来源。

## 全组统一与最低验收

- 同一通道的颜色与方向符号全稿一致；方向重叠、缺失/多余墨迹、端点各有稳定含义。图 2 的“多标签黑色”和图 5 的“两个掩膜重叠灰色”须在各自图例中区分。
- 字号分为面板标题、主体标注、辅助注释三个层级即可；按最终论文栏宽检查，关键文字以约 8 pt 以上为设计目标，不能只在放大的屏幕图上验收。
- 图像区域保留相同坐标、原始纵横比与必要空白；不要为了显得充满图框而对不同样本使用不透明的非等比拉伸。
- 科学掩膜保持原像素值；图形文字、箭头、坐标轴与图例尽量输出为矢量 PDF/SVG。PNG 用于预览，PDF 用于正文。
- 全稿编译后核对图序、图注面板字母、正文引用和页面实际尺寸。检查标题碰撞、裁切、丢字、色标含义、样本 ID、统计小数位与冻结结果的一致性。
- 不新增模型运行、不改数据、不改选样、不修改人工评分。视觉改稿的成功标准是同一证据更容易被读懂和复核。
