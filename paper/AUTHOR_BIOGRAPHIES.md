# Draft author biographies

These biographies are 50--100 words each and are intended for the IJDAR
submission package. Each author should verify the wording.

## When and how the photographs are submitted

Checked against the journal on 2026-09-17. Two findings matter:

1. **Do not send anything at initial submission.** The SNAPP `Files` page for
   this journal has four slots (manuscript, figures and tables, supplementary
   material, related files) and none of them is a biography or photograph
   slot. Springer requests author biographies at the **production stage,
   after acceptance**, normally by e-mail from the production editor (or
   through the biography form they send with the proofs). Nothing has to be
   prepared for the 20 September deadline.
2. **IJDAR does not publish these in the article.** Two recent IJDAR papers
   were checked directly (Zhang et al. 2026, DOI `10.1007/s10032-025-00559-1`;
   Baloun et al. 2025, DOI `10.1007/s10032-025-00538-6`). Neither contains a
   biography section or any photograph; both end with "Author information",
   which holds affiliations only. The requirement in the Instructions for
   Authors is inherited boilerplate from the Springer Nature template, so it
   may never actually be asked for.

If production does ask, supply one file per author, or a single document
containing all three biographies with the photographs. Use these
specifications, which come from the journal's own artwork guidelines:

| Property | Value |
| --- | --- |
| Content | Head and shoulders, plain background, passport-style |
| Colour | Black and white (grayscale) |
| Size | Passport size; roughly 35 x 45 mm or 2 x 2 in is safe |
| Resolution | At least 300 dpi (the journal's halftone minimum) |
| Preferred format | TIFF (their stated preference for halftones); JPEG or PNG are normally accepted |
| Naming | Include the surname, e.g. `Liu_photo.tif`, so it is unambiguous when three arrive together |

Supply the biography text in the same message, from the sections below, and
keep it to 50--100 words each; all three drafts are already inside that range.
